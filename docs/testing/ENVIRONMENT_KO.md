# Steam Deck 대상 환경 기록

게임을 종료한 뒤 데스크톱 모드 Konsole에서 실행합니다. 추가 Python 설치는 필요 없습니다.

```bash
bash tools/collect_environment.sh "/게임/폴더" "$HOME/re8-environment-01"
```

첫 인자는 `re8.exe`가 있는 폴더입니다. 두 번째는 **아직 없는 새 폴더**여야 하며 게임 폴더 밖에 둡니다. 기존 결과를 덮어쓰지 않습니다. 출력은 `environment.txt` 하나입니다. 게임 파일·세이브·모드 설정을 수정하지 않습니다.

출력의 `unconfirmed` 항목은 확인 후 직접 기록하세요.

- Steam 게임 속성의 호환성에서 선택한 Proton 버전(기본값이면 기본값임을 기록).
- REFramework 메뉴에서 표시되는 버전. `dinput8.dll` 해시만으로 버전을 추정하지 않습니다.
- 게임 내 RT OFF 여부, 해상도, 프레임 제한, TDP.

`environment.txt`를 제공하면 해당 실행 파일을 정확히 식별할 수 있습니다. **해시만으로 후킹 위치를 찾을 수는 없으므로**, 이후 `re8.exe`의 비공개 분석 사본 또는 필요한 디스어셈블리 자료가 별도로 필요합니다. 실행 파일이나 개인 덤프를 공개 GitHub 이슈/저장소에 올리지 마세요.

성공은 종료 코드 0, 게임 파일 없음/인자 오류는 2, 출력 위치 거부는 3입니다. 해시 읽기 등 다른 실패도 성공으로 처리하지 않으며, 실패 시 생성한 보고서 디렉터리가 불완전할 수 있습니다.
